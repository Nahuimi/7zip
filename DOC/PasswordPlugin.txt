7-Zip Password Plugin
---------------------

This fork adds a bundled password plugin DLL for Windows builds:

  7zPasswordPlugins.dll


Purpose
-------

The plugin owns password-book related storage and query logic.
The host binaries call the plugin instead of linking password-book
storage code directly into 7zFM.exe or 7zG.exe.

Current responsibilities:

- local password-book database access
- SQLite database initialization
- password lookup by archive MD5
- password store/update by archive MD5
- CSV import/export support through the host UI

Reserved for future versions:

- password-book extension lookup


Bundled database
----------------

The password book database is a real SQLite database file:

  7zPasswordBook.db

The current Windows host stores that database in the same directory
as the main program files.

Current SQLite objects:

- table: password_entries
- unique index: ux_password_entries_archive_md5

Important:

- The internal database format is SQLite.
- User-facing import/export files use CSV, not raw database copies.


Deployment
----------

The following files must be deployed together for Windows builds that
use the password book:

- 7zFM.exe
- 7zG.exe
- 7z.dll
- 7zPasswordPlugins.dll

For development builds, the host can also find the plugin in:

  CPP/7zip/UI/PasswordPlugin/<platform>/7zPasswordPlugins.dll


Plugin API Version
------------------

Current API version:

  2

The host checks the exported API version before using the plugin.
If the version does not match, the password-book feature is disabled
for that process.


Exported API
------------

The C ABI is declared in:

  CPP/7zip/UI/FileManager/PasswordPluginApi.h

Current exports:

- Z7PasswordPlugin_GetApiVersion
- Z7PasswordPlugin_EnsureDatabase
- Z7PasswordPlugin_LoadDatabase
- Z7PasswordPlugin_SaveDatabase
- Z7PasswordPlugin_LookupPassword
- Z7PasswordPlugin_StorePassword
- Z7PasswordPlugin_QueryExtensionByMd5

Notes:

- UTF-16 is used for file paths and returned text values.
- MD5 input is ASCII lowercase/uppercase hex text.
- Z7PasswordPlugin_QueryExtensionByMd5 now accepts:
  - md5
  - archiveFileName
  - archiveSizeBytes
- archiveFileName should contain the archive file name including extension.
- archiveSizeBytes should contain the archive file size on disk in bytes.
- The current host already prepares and passes these values when local
  password-book lookup does not find a password.
- Z7PasswordPlugin_QueryExtensionByMd5 is still reserved for future use and
  currently returns E_NOTIMPL.
- The plugin stores records in table password_entries and uses the
  unique index ux_password_entries_archive_md5 for MD5 lookups.


Configuration Template
----------------------

The current implementation does not require an external config file.
However, the following template is reserved for future plugin options
such as extension lookup endpoints and timeouts:

  DOC/7zPasswordPlugins.ini.example

At the moment it is documentation only.


Command-line additions
----------------------

This fork documents the following command-line usage:

  7z sx archive.zip -o"D:\ExtractDir" -mcp=auto -y

Where:

- sx
  Smart extract. It extracts with full paths and uses smart target
  folder behavior.

- -mcp=auto
  Method/property syntax that enables automatic filename encoding
  detection for archive types that support the cp property.

- -y
  Assume Yes on all queries.


Notes about -mcp
----------------

The cp property currently accepts:

- auto
- UTF-8
- WIN
- DOS
- numeric code page id

Examples:

  7z x archive.zip -mcp=auto
  7z sx archive.rar -mcp=936 -o"D:\Out" -y


Import / export format
----------------------

The password-book page imports and exports CSV files.

Default CSV file name:

  7zPasswordBook.csv

CSV columns:

- archive_md5
- password
